# 研究需求 intake

插件不得默认用户研究网络安全或模糊测试。若用户没有明确说明，主 agent 必须先询问：

1. 研究领域、子方向和关键词是什么？
2. 本次要做检索、idea、实验设计、写作、绘图还是 PPT？
3. 目标语言、期刊/会议、时间范围和文献类型是什么？
4. 是否已有 Zotero、Wiki、论文草稿、实验结果或数据？
5. 输出写入旁路 Wiki 还是用户指定目录？
6. 是否允许导入 Zotero、发送周报邮件或调用外部检索连接器？

只有用户确认后才将领域写入 `config.yaml` 或项目 Wiki。凭据问题只询问“是否已配置对应环境变量/connector”，绝不索取 token、密码或授权码本身。
