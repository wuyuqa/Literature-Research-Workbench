---
name: visual-presentation
description: Create editable scientific figures, architecture diagrams, charts, and research presentations from approved paper content.
---

Use `nature-figure` for publication-quality Python/R figures, `imagegen` for initial visual assets, `presentations` for PPT/PPTX work, `frontend-slides` for HTML presentations, and `image-svg-pptx-pro` when a visual must be reconstructed as editable SVG/PPT content. Keep data charts reproducible from source data and code. Treat generated raster images as drafts that require human review and, where possible, conversion to editable SVG/HTML/PPT elements. Do not invent numbers or experimental outcomes. Do not run experiments; only visualize user-provided data or clearly labeled illustrative examples.
